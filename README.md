# website-test

Two static HTML pages for the **pulsereview** brand — a Jackrabbit-native review-generation product for studios.

- [`index.html`](./index.html) — single-page marketing site.
- [`design-system.html`](./design-system.html) — design tokens, type, color, and component reference.

Both files are vanilla HTML / CSS / JS. The only external dependency is Google Fonts (Geist, Bricolage Grotesque, JetBrains Mono). Open either in a browser to view.
